# MBA 冲刺陪练

一个**纯静态**的 MBA 管理类联考（199 管综 + 204 英语二）陪练页面。手机、平板、电脑都能用，双击就能学，不需要装任何东西、不需要联网、不需要后端。

为「基础不好、时间不多」的备考场景做的：每个知识点先讲人话，再给例题，再让你动手练，答错立刻告诉你**这一项为什么错**。

## 内容规模

| 板块 | 章节 | 讲解 | 公式卡 | 例题 | 练习 |
| --- | --- | --- | --- | --- | --- |
| 数学 | 10 | 35 节 | 57 张 | 30 道 | 30 道 |
| 逻辑 | 9 | 36 节 | 49 张 | 27 道 | 27 道 |
| 英语 | 9 | 35 节 | 26 张 | 27 道 | 27 道 |
| **合计** | **28** | **106 节** | **132 张** | **84 道** | **84 道** |

另外还有三块独立内容：

- **单词库**：950 词，38 组。分两层——「高频核心」650 词按词频从高到低排，「主题精讲」300 词按题材成组（阅读动词、经济、环保、态度词、熟词僻义……）。每词带音标、词性、释义、一句记忆提示。
- **考前必背**：178 条高频事实，覆盖全部 28 章，例：「30 以内的质数有 10 个」「方差与标准差的关系」。
- **错题本**：答错自动入库，整题带各选项解析，可逐条「我懂了，移出」。

## 特点

**例题和练习都有逐选项解析。** 共 336 条。不是复述正确答案，而是写「你为什么会选到这一项」：

> 例：某题选 41 →「只验了每 6 人一组多 5 人这半句，41÷8 余 1」；选 45 →「取了区间中间值靠猜」；选 49 →「把差同当成了余同」。

逻辑题写成谬误类型（否定前件、中项不周延），英语题写成命题手法（偷换主体、无中生有、以偏概全）。

**例题分步展开，不剧透。** 点「先想 30 秒，再看解析」一步一步放，走到最后答案才公开，此时才浮出各错误选项的原因。

**单词卡遮住自测。** 先只给英文，自己回想，再点开看中文。认识点「认识」，拿不准点「不认识」入生词本，之后可以只刷生词本。

**进度存在本机。** 章节完成、错题、单词掌握情况、必背勾选全在浏览器 `localStorage`（键名 `mba_prep_v1`）。换设备不共享，也不会上传到任何服务器——这是它能离线秒开的原因。

## 怎么用

**电脑**：直接双击 `index.html`。

**手机**：把整个目录放到任意静态托管上（GitHub Pages、Vercel、对象存储都行），用手机浏览器打开，再通过菜单里「添加到主屏幕」，之后就是一个独立图标的全屏应用。

**本地起个服务**（可选，只是为了模拟真实 HTTP 环境）：

```bash
python -m http.server 8080
# 然后访问 http://localhost:8080
```

## 数据结构

数据文件都是普通 `<script>`，往 `window` 上挂数组，没有构建步骤、没有 import。

**章节**：

```js
window.MATH_CHAPTERS = [{
  id: 'math-01',
  title: '整除与余数',
  brief: '一句话说明这章解决什么',
  minutes: 12,
  tags: ['基础'],
  hook: '开篇的引子，说清为什么值得学',
  sections: [{ h: '小标题', p: '讲解正文，支持 <strong> 等行内标签' }],
  formulas: [{ name: '同余式', body: 'a ≡ b (mod m)' }],
  examples: [{
    q: '题干',
    options: ['A', 'B', 'C', 'D', 'E'],
    answer: 2,
    steps: ['第一步', '第二步', '第三步'],   // 逐步展开
    point: '这道题要记住的一句话'
  }],
  practices: [{
    q: '题干',
    options: ['A', 'B', 'C', 'D'],
    answer: 1,
    explain: '整体解析'
  }]
}]
```

**逐选项解析**存在 `window.OPTION_WHY`，键名规则：练习题 `章节id + '-p' + 序号`，例题 `章节id + '-e' + 序号`。值是与 `options` 等长的字符串数组，**正确项留空字符串**，错误项各写一句原因。

```js
window.OPTION_WHY['math-01-p0'] = [
  '只数了 2 的幂，漏了那个 3',   // A 错
  '',                            // B 对
  '1×2×3×4 只有 2³，保证不了 2⁴', // C 错
  '把因数个数当成了因数本身'       // D 错
];
```

**单词**：

```js
{ w: 'comprehensive', p: 'ˌkɒmprɪˈhensɪv', pos: 'adj.', cn: '全面的', tip: '记忆提示' }
```

加了题或词，页面上的数字会自动跟着变（单词组数、总词数、错题数都从数据实时算，没有写死的文案）。

## 兼容性

纯 ES5，没有箭头函数、`const`、模板字符串、展开运算符，老浏览器和旧版 WebView 也能跑。CSS 用自定义属性做主题切换，`data-theme="light|dark"`。
